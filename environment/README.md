# Software environment

The demonstration and scientific tests can be executed
using the Python dependencies recorded in this directory.

`requirements-demo.txt` specifies the principal scientific
libraries. `requirements-lock.txt` records the complete
dependency resolution used for isolated verification.

These are the dependencies of a compatible verification
environment. Historical execution environments are documented
separately in the study's computational records.

A successful demonstration run is not a substitute for
reproducing the empirical study results.
