# Researcher-defined question extensions

**Supplementary only.** Researcher-defined questions cannot modify CORE-8, the original survey questions or the original 33 predictors. The additional information is independent of original WSQS scores. Contributor submissions are voluntary and must not include respondent data.

1. Make a private copy of `extensions_input/EXAMPLE_DISABLED.json`. Set `enabled` to `true` and provide an unused `EXT_` question ID, wording, response kind, any allowed response choices, domain, source, provenance, applicability, contributor and consent-review flag. Up to 31 enabled questions fit the extension-entry sheet. Obtain study-specific consent/ethics approval.
2. Generate a printable **editable supplementary Word questionnaire**, blank extension CSV template and supplementary codebook with `python tools/build_extension_supplement.py --extensions /private/enabled_specs --output /private/blank_supplement_01`. To obtain a PDF, export the Word supplement as PDF. These materials do not revise the original research survey or CORE-8 PDF.
3. In a **private working copy** of `WSQS_International_Calculator.xlsx`, open `EXTENSION ENTRY`. Put each registered extension ID in row 4, one column per question. Use record IDs matching `RESEARCH ENTRY` (rows 5–104) and select/write permitted answers. The extension sheet is distinct from core scoring and never changes `MY WSQS` or `RESEARCH ENTRY` formulas.
4. Export complete responses with `python tools/extract_research_entry.py --input /private/complete.xlsx --extensions /private/enabled_specs --output /private/response_export_01`. The exporter validates metadata, permitted values and record ID alignment and rejects unregistered extra columns.
5. Run `python run_toolkit.py --input /private/response_export_01/PRIVATE_RESEARCH_RESPONSES.csv --extensions /private/enabled_specs --output /private/descriptives_01 --analysis descriptive` for supplementary response counts. A supplementary *model* uses separate fully harmonized 33-predictor inputs and `python run_advanced.py --input /private/harmonized_with_extensions.csv --extensions /private/enabled_specs --output /private/extension_fit_01 --mode extension-model`.

No extension is enabled by default. A supplementary extension model is **not** the original published model. Never publish completed questionnaires, private Excel files or exported respondent records. If a researcher changes CORE-8, that is a new measure requiring a new name and validation.

**Execution provenance:** For independent-study `run_toolkit.py` and `run_advanced.py` runs using `--extensions`, the private `executed_sources` directory contains exact copies of enabled registry JSON definitions and the extension/provenance Python modules. Their file hashes appear in `RUN_REPORT.json`; do not publish these files without checking contributor rights.
