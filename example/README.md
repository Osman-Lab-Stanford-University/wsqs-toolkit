# Synthetic demonstration

The 25 examples are generated for testing the computational
procedures. They are not sampled from the household survey.

Each example contains the required responses for CORE-8
scoring and the complete predictor-construction input schema.

The file `expected_scores.csv` contains the corresponding
CORE-8, CORE-7A and CORE-7B demonstration scores.

The provider applicability indicator is supplied separately
from the primary domestic provision category. It follows
the scientific feature-construction interface.

Run the repository tests to verify scoring, feature
construction and provider-dependent response handling.

Performance metrics obtained using these examples should
not be compared with empirical results from the study.
